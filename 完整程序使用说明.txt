离线语音记账 · Windows 免安装版

一、启动和分享
1. 适用于 Windows 10/11 的 64 位电脑，需要麦克风。
2. 双击“离线语音记账.exe”，然后点击“开始聆听”。
   程序先检查 Windows 麦克风访问状态和设备能否实际打开，可用后才加载语音模型并聆听。
   若权限未开启，会弹出提示。点击“打开麦克风权限设置”，在 Windows 设置中开启相关开关，
   返回弹窗点击“重新检测并开始”，即可再次检查并继续聆听。
   若未连接麦克风或设备不可用，会显示相应提示，并提供声音设置入口。
   弹窗也可点击“暂不使用麦克风”，继续使用文字与手动记账。
3. 第一次启动会从本地加载模型，稍等几秒即可。无需联网、账户、Python 或 Excel。
4. 发给朋友时，把整个“应用”文件夹复制或压缩后发送。朋友解压后双击 EXE 即可使用。
5. 请保留“_internal”和“模型”文件夹。仅发送 EXE 会缺少运行库或模型。
6. 也可双击“安装到本机.cmd”：复制到当前用户的本地应用目录，并创建桌面快捷方式，无需管理员权限。

二、语音格式
激活文字：记账
完整示例：记账，清风，4个88A硒鼓
也可以说：记账，李凌宇，三只八十八A硒鼓 / 记账，王小明，两套十二A墨盒。
A 按英文字母发音。识别到“记账”后开启固定 120 秒的记录窗口，界面显示倒计时。
先说姓名和第一项账目，随后可以停顿并继续说其他产品；窗口内后续识别到的内容都会累积。
例如先说“记账，清风，4个88A硒鼓”，再说“1只12A硒鼓”，最后说“9个12A碳粉”。
两分钟结束后，会合并成一行：清风 | 4个88A硒鼓1只12A硒鼓9个12A碳粉。
第一句话完整也不会提前写入。重复说“记账”不会清空内容或重新计时。
一个记录窗口对应一个姓名；窗口内的其他话语也会成为该条账目内容。
点击“结束本次记录”可提前结束；开启自动写入时会立即整理并保存。
到达截止时间时，程序会整理截止前尚在识别的最后一段语音，再完成保存，可能需要稍等几秒。
窗口结束后不会继续追加普通话语；需要再次说“记账”才能开启下一次记录。
点击“停止聆听”会提前结束本次记录并停止麦克风；退出时会保留已经识别到的内容。
程序不保存录音，只累积语音识别出的文字。
账目内容保留数量、型号及产品名称，例如“4个88A硒鼓”，不再要求以英文字母结束。
口述的“三个八十八A硒鼓”会规范为“3个88A硒鼓”。
语音中型号后面的常见同音误识别“硒谷”会纠正为“硒鼓”，原识别文字仍显示在界面。
若识别没有姓名分隔标点，程序会根据已配置姓名或数量单位定位账目起点。
建议清晰说出姓名并稍作停顿，接着说账目。不能确定分界时请在界面中手动修正。

三、账目文件
程序自动寻找当前登录用户的真实桌面位置，包括重定向到 OneDrive 的桌面。
桌面没有“账目”文件夹则新建；已存在则继续使用。
每个人分别保存为“姓名.xlsx”，如“李凌宇.xlsx”。
没有文件则新建，有文件则在“账目”工作表末尾追加一行。
若现有工作簿没有“账目”工作表，会追加到第一个可见工作表。
第一行是表头，三列依次为：系统时间、姓名、账目。
示例数据：2026-10-13 12:34:56 | 清风 | 4个88A硒鼓。
时间采用电脑本地系统时间，精确到秒，保存为 Excel 日期时间，可排序。
数量与型号合并保留在“账目”列，产品名称也一并保存。不会联网查询或更正系统时间。
向旧版四列表格再次写入时，会先在“账目/迁移备份”中保存原始文件副本，
然后把旧行的“数量”和“类型”拼接成“账目”，删除旧的类型列，并追加新行。
例如旧行“3个 | 12A”会变成“3个12A”。迁移后仍使用原来的姓名.xlsx 文件。
旧版本地待写入队列和历史记录会自动兼容为合并后的账目内容。
如果现有表格有自定义表头或额外列，程序会保留待写入记录并提示核对格式。
工作簿中有一个隐藏的“_应用记录”工作表，用来防止失败重试产生重复行，请保留它。

四、姓名识别与手动纠正
姓名中的同音字无法仅靠声音区分，第一次使用请观察“识别结果”。
点击“姓名纠正设置”，明确添加你常用姓名和识别结果的对应关系：
李凌宇=李玲宇|李灵宇
张三=张三
每行一人。左侧是真实姓名，右侧是可能识别出的写法，以 | 分隔。
没有配置的姓名按识别文字保存；不会自动猜测其正确写法。
已预置示例姓名“李凌宇”的同音纠正：李玲雨、李玲宇、李凌雨、李灵宇。
如果你有客户真实姓名恰好是其中一种写法，请在姓名纠正设置中修改或删除该对应关系。
如果姓名中含有数字（例如“张三”），建议把姓名加入设置，避免中文数量边界歧义。
“自动写入”默认开启：两分钟结束或点击“结束本次记录”后自动追加一行。
取消“自动写入”，窗口结束后可以检查并修改姓名和全部账目，再点击“保存一条”。
正在记录时姓名与账目显示为只读；需要修改时请先结束本次记录，并取消自动写入。
尚有未保存草稿时，请先保存，或点击“清空未保存草稿”，再开启下一次记录。
“解析文字”仅填入待保存字段，不会自动入账。需点击“保存一条”才会写入。
手动保存两次会新增两条，这是两次独立记账操作。
若已写入的语音识别有误，请打开对应 XLSX 修正该行，避免再保存造成重复记录。

五、文件占用、恢复和数据位置
写入失败时会显示“待写入”，已接收记录保留在当前用户本地。
如果 XLSX 正在 Excel/WPS 中打开，请关闭对应文件，然后点击“重试未写入”。
下次启动程序也会自动重试尚未写入的记录。
设置、写入历史及待写入队列位于：%LOCALAPPDATA%\OfflineVoiceLedger。
两分钟内的已识别文字会保存为本地草稿，程序意外关闭后可以恢复到界面并手动确认保存。
没有识别出完整姓名和账目的内容不会丢弃，会保留为草稿，供手动补全。
恢复草稿后不会自动重新开启或延长计时；请检查后保存，或清空草稿。
程序不保存录音，不向网络发送语音、账目或姓名。
分享应用文件夹不会携带这些个人记录；账目和本地历史位于各自电脑。
如果确实需要完整迁移账目和历史，请另外复制桌面“账目”和上述本地数据文件夹。
两台电脑各自独立记账，不自动同步。

六、常见问题
无法启动聆听：检查麦克风是否连接，在下拉框选择设备；必要时点击“刷新”。
Windows 设置 → 隐私 / 隐私和安全性 → 麦克风，允许桌面应用访问麦克风。
开启“麦克风访问权限”“允许应用访问麦克风”“允许桌面应用访问麦克风”。
普通桌面程序通过系统设置配置权限，不能在应用弹窗里代替 Windows 直接切换授权开关。
如果设置由组织管理，需联系电脑管理员。程序不会修改系统权限或注册表。
没有输入设备时，文字测试和手动记账仍可使用。
语音识别受口音、环境噪声和发音影响，建议普通话、靠近麦克风，并清晰读出型号。
新电脑上建议先取消自动写入，试说几条并设置姓名纠正，再启用自动写入。
本程序为本地打包的应用，没有数字签名。
卸载：关闭程序，删除安装目录和桌面快捷方式即可。账目和历史会保留。
