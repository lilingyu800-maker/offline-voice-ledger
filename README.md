# 离线语音记账

一个面向 Windows 的本地语音记账小工具。由李凌宇（清风）提出需求，OpenAI Codex 协助开发。希望分享实际使用经验，也欢迎大家通过 Issues 指出问题、通过 Pull Requests 帮忙改进。

这是个人学习和分享项目，不是 OpenAI 官方产品。语音识别可能出错，实际账目请人工核对并定期备份。本项目不保证识别准确率、数据绝不丢失或适用于所有业务场景。

## 当前功能

- 使用本地 SenseVoice Small INT8 和 sherpa-onnx 识别语音，正常记账不需要云端 API 或 API 密钥。
- 说“记账，清风，四个八十八A硒鼓”开启固定 120 秒记录窗口。
- 窗口内继续说的内容合并成一条账目，也可手动提前结束。
- 按姓名写入桌面 `账目/姓名.xlsx`，三列为系统时间、姓名、账目。
- 支持姓名纠正、手动记账、草稿恢复、写入失败重试和旧版表格迁移备份。

## 这份仓库包含什么

本次发布的是源码版，包含源代码、测试、安装脚本、构建说明和第三方许可说明。**没有附带 EXE、运行库、模型权重和测试录音，下载 ZIP 后不能直接双击运行。** 安装脚本仅供完成打包后的分发使用。

已在本机使用的完整程序，其操作方法见 [完整程序使用说明](完整程序使用说明.txt)。该说明描述完整安装包；提到的随附模型和音频不包含在本源码仓库中。

## 开发者运行

需要 Windows x64、Python 3.12（包含 Tkinter）。在仓库根目录打开 PowerShell，安装依赖阶段需要联网：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\源码\requirements.txt
```

按 [模型准备说明](模型准备.md) 自行从上游获取模型并阅读其协议，文件位置应为：

```text
模型/sensevoice/model.int8.onnx
模型/sensevoice/tokens.txt
模型/sensevoice/silero_vad.onnx
```

然后运行：

```powershell
.\.venv\Scripts\python.exe .\源码\main.py
```

没有模型时仍可使用手动记账，开始语音识别会提示模型缺失。不要把模型、真实账目或个人设置提交到仓库。

## 检查与构建

不需要麦克风录音或模型的现有单元测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s .\源码 -p "test_*.py"
```

准备模型后的离线自检：

```powershell
.\.venv\Scripts\python.exe .\源码\selftest.py
```

可选的 `--audio` 打包自检需要另行提供符合预期内容的录音。本仓库没有测试 WAV，因此默认只运行不带音频参数的自检。打包方法见 [源码/重建说明.txt](源码/重建说明.txt)。构建得到的 EXE 还需要重新核对分发包中的全部组件许可证，再发布。

## 已知限制，欢迎指点

- 姓名依靠识别文字和人工配置，不能通过声纹判断说话人。
- 一个记录窗口只对应一个姓名，窗口内其他话语也会累计进账目。
- 没有标点、没有数量单位且姓名未配置时，可能无法正确拆分姓名和账目。
- 目前是规则解析，不是可以理解任意自然语言的智能会计系统。
- 本机测试不能代替不同麦克风、口音和实际工作环境下的验证。

## 隐私与许可

录音在内存中用于识别，应用不主动保存录音文件。识别文字、草稿、历史及姓名设置保存在 `%LOCALAPPDATA%\OfflineVoiceLedger`，Excel 在桌面 `账目/`。本地文件未加密，设备用户应自行管理访问权限。不要在 Issues 或截图中公开真实客户资料。
